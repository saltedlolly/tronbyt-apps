Tronbyt Server

Install apps directly to your Tronbyt devices.

Requires Tronbyt Server v2.x.x or later.

Enter your Tronbyt Server address above and select Verify. Your server opens in a new tab: sign in if asked, and it comes straight back to the App Viewer. For a local address without a port, the default port 8000 is used (19191 for umbrel.local). Local addresses only work on the same network as the server.
